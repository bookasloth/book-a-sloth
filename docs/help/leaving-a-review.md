# Leaving a review

## When you can review

You can review a booking once it's **completed** — after the session has happened and is marked done. Before that, there's nothing to review yet.

A **Leave a Review** option appears on that booking once it's complete. You give a rating from 1 to 5 and can add a few words.

## One review per booking

You can leave **one review per booking.** If you've already reviewed it, you'll see that you have — you can't submit a second one for the same booking.

## Where to find it

Go to your [My Bookings](/my-bookings) page (or your [Reviews](/reviews) page for ones you've left), open the completed booking, and use the review option there.

## The host can review you too

Reviews go both ways on Book A Sloth — after a completed booking, the host can also leave a review. It's how both sides build trust.
